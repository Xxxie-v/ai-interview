# 项目入口与整体架构

## 启动入口

- 后端入口：[App.java](../../app/src/main/java/interview/guide/App.java)
- 后端依赖：[build.gradle](../../app/build.gradle)
- 后端配置：[application.yml](../../app/src/main/resources/application.yml)
- 前端入口：[main.tsx](../../frontend/src/main.tsx)
- 前端路由：[App.tsx](../../frontend/src/App.tsx)
- 本地依赖：[docker-compose.yml](../../docker-compose.yml)

`App.java` 负责启动 Spring Boot 和定时任务。后端按以下方向调用：

```text
HTTP/WebSocket
  -> Controller / WebSocketHandler
  -> Service
  -> Repository 或 Infrastructure
  -> PostgreSQL / Redis / RustFS / LLM
```

## 后端分包

```text
interview.guide
├── common
│   ├── ai             ChatClient、Advisor、结构化输出、Prompt 防护
│   ├── annotation     @RateLimit
│   ├── aspect         Redis Lua 限流切面
│   ├── async          Redis Stream 生产者/消费者模板
│   ├── config         Security、S3、CORS、LLM 等配置
│   ├── evaluation     文本和语音共用的评分服务
│   ├── exception      业务异常和全局异常处理
│   └── result         Result<T> 统一响应
├── infrastructure
│   ├── export         PDF 导出
│   ├── file           文件校验、解析、存储
│   ├── mapper         MapStruct Mapper
│   └── redis          Redis 通用服务和文本面试缓存
└── modules
    ├── auth           用户、角色、JWT、短信
    ├── hr             HR 面试结果查看
    ├── resume         简历
    ├── interview      文本面试
    ├── voiceinterview 语音实时面试
    ├── knowledgebase  RAG 知识库
    ├── interviewschedule 面试日程
    └── llmprovider    模型供应商管理
```

## 数据流中的外部组件

- PostgreSQL：JPA 业务数据及 pgvector 向量数据。
- Redis/Redisson：缓存、限流、分布式锁、Redis Stream 异步任务。
- RustFS：通过 AWS S3 SDK 存储简历和知识库文件。
- DashScope/OpenAI 兼容接口：LLM、Qwen ASR、Qwen TTS。

# AI 与基础设施

## ChatClient 和 Advisor

[LlmProviderRegistry.java](../../app/src/main/java/interview/guide/common/ai/LlmProviderRegistry.java)
根据 Provider 配置动态创建并缓存三类客户端：

- 默认 ChatClient：可包含 ToolCall、Memory、Logger、SafeGuard Advisor。
- Plain ChatClient：结构化输出场景使用，不挂载 Skills Tool。
- Voice ChatClient：语音面试使用，启用流式 ToolCall，不使用自动 Memory。

Provider 配置来源包括 `application.yml` 和数据库中的运行时配置，API Key 使用
`ApiKeyEncryptionService` 加密。

## 结构化输出与 Prompt 安全

- [StructuredOutputInvoker.java](../../app/src/main/java/interview/guide/common/ai/StructuredOutputInvoker.java)：
  调用模型、用 `BeanOutputConverter` 转换结果，并在格式失败时重试。
- [PromptSanitizer.java](../../app/src/main/java/interview/guide/common/ai/PromptSanitizer.java)：
  清洗简历、JD、知识库等外部文本。
- [PromptSecurityConstants.java](../../app/src/main/java/interview/guide/common/ai/PromptSecurityConstants.java)：
  统一 Prompt 安全约束。
- [prompts](../../app/src/main/resources/prompts)：简历、出题、评估、RAG Prompt 模板。

## 共用评分

[UnifiedEvaluationService.java](../../app/src/main/java/interview/guide/common/evaluation/UnifiedEvaluationService.java)
同时被文本面试和语音面试复用。它将问答分批送入 LLM，生成每题评价，再合并总分、分类分、
优势、改进项、反馈和参考答案。

## Redis

- [RedisService.java](../../app/src/main/java/interview/guide/infrastructure/redis/RedisService.java)：
  String、Hash、List、锁、计数器、Stream 通用操作。
- [AbstractStreamProducer.java](../../app/src/main/java/interview/guide/common/async/AbstractStreamProducer.java)
- [AbstractStreamConsumer.java](../../app/src/main/java/interview/guide/common/async/AbstractStreamConsumer.java)
- [AsyncTaskStreamConstants.java](../../app/src/main/java/interview/guide/common/constant/AsyncTaskStreamConstants.java)

现有三个 Stream 管道分别处理简历分析、文本面试评估和知识库向量化；语音评估也使用相同
模板。

## 文件和对象存储

```text
MultipartFile
  -> FileValidationService
  -> ContentTypeDetectionService
  -> FileHashService
  -> FileStorageService
  -> S3Client
  -> RustFS
```

重点文件位于 [infrastructure/file](../../app/src/main/java/interview/guide/infrastructure/file)。
当前 `FileStorageService` 是具体实现，尚未抽象 `ObjectStorageService`，也没有预签名 URL。

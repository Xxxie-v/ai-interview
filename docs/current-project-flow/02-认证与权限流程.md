## 用户名/密码登录

```text
POST /api/auth/login
  -> AuthController.login
  -> AuthService.login
  -> UserRepository 按用户名或手机号查用户
  -> BCrypt 校验密码和 enabled
  -> JwtService.createAccessToken
  -> RefreshTokenService.create
  -> 返回 accessToken + refreshToken + 当前用户
```

后续请求由 `JwtAuthenticationFilter` 读取 `Authorization: Bearer ...`，验证 JWT 后再次查询
用户表。只有用户仍存在且 `enabled=true` 才会写入 Spring SecurityContext，因此禁用用户的
已有 access token 也会失效。

## Refresh Token

```text
POST /api/auth/refresh
  -> 查找 token SHA-256 哈希
  -> 校验未撤销且未过期
  -> 立即撤销旧 token
  -> 签发新 access token 和 refresh token
```

数据库只保存 refresh token 哈希，不保存明文。

## 当前短信流程

```text
POST /api/auth/sms/send
  -> SmsVerificationService
  -> Redis 检查手机号 60 秒冷却
  -> NoopSmsSender 或 AliyunPnvsSmsSender

POST /api/auth/register/phone
  -> 校验短信验证码
  -> 创建 CANDIDATE 用户
  -> 签发 Token
```

注意：当前实现是“手机号验证后注册”，不是需求中的“短信验证码直接登录”。Noop 实现目前
还会返回并记录验证码，阅读代码时不要把它当作最终安全设计。

## 当前角色和权限

- 角色：`ADMIN`、`HR`、`CANDIDATE`。
- 权限：`APP_ACCESS`、`ADMIN_MANAGE`、`HR_INTERVIEW_VIEW`。
- URL 规则：`/api/admin/**` 需要 ADMIN，`/api/hr/**` 需要 HR 或 ADMIN，其余 `/api/**`
  默认只要求登录。
- 当前尚未启用 `@EnableMethodSecurity`，也没有 `@PreAuthorize`。

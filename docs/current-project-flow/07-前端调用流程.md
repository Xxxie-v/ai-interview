# 前端调用流程

## 应用入口与路由

- [main.tsx](../../frontend/src/main.tsx)：挂载 React 应用。
- [App.tsx](../../frontend/src/App.tsx)：页面路由和懒加载。
- [ProtectedRoute.tsx](../../frontend/src/components/ProtectedRoute.tsx)：要求用户已登录。
- [RoleRoute.tsx](../../frontend/src/components/RoleRoute.tsx)：前端角色路由控制。
- [Layout.tsx](../../frontend/src/components/Layout.tsx)：导航和登出入口。

前端角色判断只用于界面控制，真正的权限边界仍必须由后端保证。

## HTTP 认证链路

```text
AuthPage
  -> api/auth.ts
  -> api/request.ts
  -> Authorization: Bearer accessToken
  -> 后端 SecurityFilterChain

接口返回 401 业务错误
  -> request.ts 使用 refreshToken 调 /api/auth/refresh
  -> 保存新 Token
  -> 重放原请求
```

相关文件：

- [AuthPage.tsx](../../frontend/src/pages/AuthPage.tsx)
- [auth.ts](../../frontend/src/api/auth.ts)
- [request.ts](../../frontend/src/api/request.ts)
- [authStorage.ts](../../frontend/src/utils/authStorage.ts)

## 文本面试页面

```text
InterviewHubPage 选择技能、简历、难度和模型
  -> InterviewPage
  -> api/interview.ts 创建/恢复会话
  -> 获取当前题目
  -> 提交或暂存答案
  -> 完成面试
  -> 轮询/读取报告
```

- [InterviewHubPage.tsx](../../frontend/src/pages/InterviewHubPage.tsx)
- [InterviewPage.tsx](../../frontend/src/pages/InterviewPage.tsx)
- [interview.ts](../../frontend/src/api/interview.ts)

## 语音面试页面

```text
VoiceInterviewPage 创建或恢复会话
  -> connectWebSocket
  -> AudioRecorder 获取麦克风 MediaStream
  -> WebSocket 发送音频数据
  -> 接收字幕、AI 文本和 TTS 音频
  -> 暂停/恢复/结束
  -> VoiceInterviewEvaluationPage 展示评估
```

- [VoiceInterviewPage.tsx](../../frontend/src/pages/VoiceInterviewPage.tsx)
- [AudioRecorder.tsx](../../frontend/src/components/AudioRecorder.tsx)
- [voiceInterview.ts](../../frontend/src/api/voiceInterview.ts)
- [RealtimeSubtitle.tsx](../../frontend/src/components/RealtimeSubtitle.tsx)
- [VoiceInterviewEvaluationPage.tsx](../../frontend/src/pages/VoiceInterviewEvaluationPage.tsx)

当前 `AudioRecorder` 仅请求 `audio: true`，还没有摄像头预览、设备联合检查或视频
`MediaRecorder` 分片上传。

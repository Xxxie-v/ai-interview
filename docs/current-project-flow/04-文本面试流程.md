# 文本面试流程

## 创建会话和生成问题

```text
POST /api/interview/sessions
  -> InterviewController.createSession
  -> InterviewSessionService.createSession
  -> 校验 resumeId 属于当前用户
  -> InterviewQuestionService.generateQuestionsBySkill
  -> 读取技能模板、简历、JD、历史问题
  -> LlmProviderRegistry 获取 ChatClient
  -> StructuredOutputInvoker 生成结构化问题
  -> InterviewPersistenceService 保存 InterviewSessionEntity
  -> InterviewSessionCache 写入 Redis
```

问题生成会组合技能方向题、简历题和追问，并有 fallback 问题用于 AI 调用失败场景。

## 回答与完成

```text
GET  /sessions/{sessionId}/question
  -> 从 Redis 缓存读取当前问题，未命中时由数据库恢复

POST /sessions/{sessionId}/answers
  -> Controller 校验 sessionId 属于当前用户
  -> InterviewSessionService.submitAnswer
  -> InterviewPersistenceService 保存答案
  -> 更新当前问题索引和缓存

POST /sessions/{sessionId}/complete
  -> 状态改为 COMPLETED
  -> EvaluateStreamProducer 写入 Redis Stream
  -> EvaluateStreamConsumer 异步调用 AnswerEvaluationService
  -> UnifiedEvaluationService 批量结构化评分
  -> 写回总分、反馈、优势、改进项及参考答案
```
